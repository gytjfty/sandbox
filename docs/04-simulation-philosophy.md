# 4. Simulation Philosophy

The simulation operates at multiple levels.

| Scale      | Examples                                 |
| ---------- | ---------------------------------------- |
| Individual | People, animals, plants, objects         |
| Local      | Settlements, ecosystems, weather         |
| Regional   | Economies, societies, infrastructure     |
| Global     | Climate, civilization, planetary systems |
| Long-term  | Evolution, geological change, history    |

Some things are simulated in considerable detail; others use abstractions and approximations.

The important part is consistency between levels.

The game doesn't need to simulate every molecule, but it should represent the underlying properties and interactions necessary for meaningful outcomes.
