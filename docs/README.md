## Overall Vision

A first-person, planetary-scale, persistent simulation where individuals, organisms, societies, technology, nature, and physical systems all coexist and influence one another. The player is free to participate in this world however they want, while the world continues to evolve independently.

The central ambition isn't to create a game with an enormous number of features. It's to create a world where those features actually interact and produce outcomes we didn't explicitly script.
